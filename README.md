05). System Overview

CampusShare is a mobile application designed to help university students discover, share, lend, and borrow academic resources such as books, notes, past papers, and other study materials.

The system provides user authentication, resource listing and browsing, resource management, and borrowing request management through a mobile application connected to a REST API backend and MongoDB database.
